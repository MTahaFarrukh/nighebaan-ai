3. WhatsApp Bot (Baileys) Terminal Setup & .env Configuration Guide

WhatsApp monitoring uses @whiskeysockets/baileys. Because WhatsApp Web requires a persistent 24/7 WebSocket connection, local session auth (auth_baileys), and a residential IP against cloud IP bans, the WhatsApp client runs locally on the terminal and dispatches messages to the live cloud Render API:

A. Terminal Execution (Git Clone & Run)

git clone https://github.com/MTahaFarrukh/nighebaan-ai.git cd nighebaan-ai/whatsapp npm install npm run dev
Scan the QR code printed in the terminal via WhatsApp Linked Devices.

B. Configuration File (whatsapp/.env)

WHATSAPP_API_KEY="render-par-rakha-hua-32-char-key" WHATSAPP_DEMO_JID="923001234567@s.whatsapp.net" WHATSAPP_GUARDIAN_JID="923117654321@s.whatsapp.net" WHATSAPP_OWNER_OPT_IN="true" DRY_RUN="true" # true for logs, false for live alerts BACKEND_API_URL="https://nighebaan-ai.onrender.com/api"
Privacy & Security Note: Under course privacy rules, personal phone numbers and active auth states are strictly gitignored (.gitignore). Evaluators configure their own recipient numbers in whatsapp/.env prior to running.
