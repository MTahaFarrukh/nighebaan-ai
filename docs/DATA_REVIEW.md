# M1 human review handoff

The local pack is in `backend/data/raw/custom/review_v1/`. All draft text and
review files are ignored by Git. They contain synthetic examples only. Do not
replace placeholders with real phone numbers, account IDs, CNICs or chat text.

## Files to complete

- `reviewer_a.csv`: one human labels every row `normal` or `scam` and enters
  the anonymous reviewer ID `reviewer_a` in every row.
- `reviewer_b.csv`: a second human does the same independently, using
  `reviewer_b`. Do not look at the other sheet or the draft's suggested labels
  until both independent sheets have been completed.
- `review_all.csv`: review **every** candidate for correct meaning, plausible
  Roman Urdu and absence of personal data. Fill `label`, `privacy_ok` with
  `yes` only after inspection, and `reviewer` with an anonymous reviewer ID.
  After the independent sample is complete, discuss disagreements and put the
  agreed final labels in this all-item sheet. Preserve original independent
  labels so Cohen's kappa measures agreement before discussion.

Use `normal` for legitimate updates and warnings about scams; use `scam` for
deceptive credential requests, impersonation, fraudulent fees or offers.
Urgency, a link or a money word alone does not make a message a scam.

Do not edit `id` or `text` in review sheets. If wording needs repair, update
the local `custom_seeds.json` and build a fresh versioned pack. The promoter
rejects changed draft/text, missing IDs, incomplete labels, absent privacy
checks and the same reviewer for both independent sheets. It cannot verify
that a person truly completed the review; do not automate human annotations.

The draft contains LLM-authored seeds expanded by shared prefixes. `source`
is honestly `llm_assisted`, not manual. Family IDs expose which examples are
closely related. Counts alone do not establish dataset quality; replace weak
or repetitive seeds during review. Do not treat template variants as
independent real-world evidence.

## Commands (from backend)

Generate a new version only when the seeds change:

```powershell
.venv/Scripts/python.exe -m ml.custom_dataset build --seeds data/raw/custom/custom_seeds.json --directory data/raw/custom/review_v2
```

After the v1 annotations and discussions are complete:

```powershell
.venv/Scripts/python.exe -m ml.custom_dataset promote --directory data/raw/custom/review_v1 --output data/raw/custom/custom_scam.csv
```

Promotion writes the loader-compatible CSV and `custom_scam.review.json`
with computed kappa, disagreement count and artifact hashes. It preserves
human-adjudicated labels and refuses to overwrite existing approved output.
No kappa has been calculated for the real draft yet. Test-suite agreement
values use artificial annotations and are not project results.

## Public corpus status

`docs/DATASET_INVENTORY.json` is generated by `ml.audit_sources`. Official
UCI archives and RUHSOLD task-1 TSVs were inspected in memory; raw text was
not persisted or logged. The inventory records download sizes, checksums,
known label counts, empty rows and duplicate counts. RUHSOLD is pinned to
the recorded Git commit. Its original partition called `test` was inventoried
for ingestion only; no model predictions or evaluation were performed.

Public availability does not guarantee absence of personal information.
Before creating local corpus inputs, an approved de-identification/review
process is still required. Do not simply save unreviewed public text, and do
not claim a regex pass is a complete privacy review. The audit tool never
fetches links found inside messages.

To repeat the audit, use a new report filename:

```powershell
.venv/Scripts/python.exe -m ml.audit_sources --output ../docs/DATASET_INVENTORY_next.json
```

Once all approved input files described in `DATASETS.md` exist, run
`python -m ml.data_prep` exactly once for the chosen corpus version. It
deduplicates globally, reserves the custom hold-out and freezes the remaining
70/15/15 partitions. Do not train or evaluate on unreviewed drafts. M1 remains
open until approved public inputs and the reviewed custom set are available.
